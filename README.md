# 🍎 사과게임

> 이 README는 게임을 완성한 뒤 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개
- 마우스 드래그로 인접한 사과들을 선택하여, **선택한 사과들의 숫자 합이 10의 배수(10, 20, 30 등)**가 될 때 사과를 없애고 점수를 얻는 퍼즐 게임입니다.
- 제한시간 2분 동안 최대한 많은 점수를 획득하는 것을 목표로 합니다.

## 어떻게 만들었나요?
- **구조 분리**: 코드를 유지보수하기 쉽도록 HTML(`index.html`), CSS(`style.css`), JavaScript(`script.js`) 3개의 파일로 나누어 구현했습니다.
- **주요 로직**:
  - 8x8 격자판에 1~9 사이의 랜덤 숫자가 적힌 사과 생성
  - 드래그 영역 계산 및 실시간 하이라이트 기능 구현
  - 드래그한 사과의 총합이 **10의 배수**일 경우 사과가 제거되도록 판정 로직 수정
  - 제한시간 타이머 및 로컬 스토리지 기반 최고 점수(High Score) 시스템 적용

## 실행 방법
1. 프로젝트 폴더 내의 `index.html` 파일을 브라우저로 엽니다. (VS Code의 `Live Server` 확장 프로그램 사용 권장)
2. 제한시간 2분 동안 마우스 드래그로 합이 10의 배수가 되는 사과 조합을 찾아 터뜨립니다.

## 커스텀이정한 부분
- 기존의 단순 합계 '10' 제한에서 벗어나, 여러 개를 넓게 드래그하여 **합이 10의 배수(10, 20, 30...)**가 될 때도 터지도록 확장하여 게임의 전략성과 재미를 높였습니다.
